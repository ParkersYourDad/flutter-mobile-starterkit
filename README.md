# Flutter Mobile Starter Kit

A production-minded Flutter foundation for Android and iOS.

## Product principles

- Premium minimal UI with neutral colors, open surfaces, subtle dividers, and no decorative elevation.
- English and Arabic with correct LTR/RTL behavior.
- Light, dark, and system appearance.
- Centralized design tokens and reusable components.
- Explicit loading, empty, error, and success states.
- Minimal dependencies, real functionality, and testable architecture.
- No placeholder features, fake integrations, unnecessary abstractions, or generated-code clutter.

## Status

The repository is in the foundation phase. Requirements, architecture, design, implementation, quality, and release are managed as sequential stages with explicit acceptance criteria. A stage is not considered complete until its handoff is accepted and its evidence is recorded.

## Stage sequence

1. Product requirements
2. Architecture and foundation
3. Design system and UX
4. Flutter implementation
5. Quality, security, accessibility, and performance
6. CI, documentation, and release readiness

See [project execution plan](docs/project/EXECUTION_PLAN.md) for ownership, handoffs, gates, and blockers.

## Target platform

Android and iOS only. Web and desktop are out of scope.

## Verification policy

Claims about build, analysis, tests, accessibility, and release readiness must be backed by actual command output or CI results. Untested work must be labelled unverified.
